# Demo script

A 2:30 video plan. Nothing is recorded yet. The canonical run (PRD section 6.2) comes first: phone breath plus ratings, fear dogs, feared outcome "it will jump on me", trials in the park and then the sidewalk, seed locked, 1080p, audio on. It must include at least one ceiling retreat produced by deliberate fast breathing, one patient step closer, the expectancy test and the ratings.

This version changes the PRD's script in four places: "Exposure fixes it" implied efficacy, "generates your fear from a sentence" over a hand-written dogs ladder overstated the pipeline, "no cut" is unmeasured, and the planned 80 to 30 rating was only a target. The last column names the claim that must pass before a line stays. If it has not passed, use the fallback wording.
