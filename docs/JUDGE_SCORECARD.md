# Judge scorecard

These are the builder's predictions. They are not scores and they are not evidence. Visko publishes three criteria and no weights, so equal weights are assumed. The predictions rest on one prior event and no published scores, and they assume the build gates G1 to G8 land. As of this writing only G2 has passed and G0 is in progress (see [GATES](GATES.md)), so the numbers describe a plan.

The builder's estimate of the likely winning score is about 85 to 88, which would leave a margin of 1 to 4 points. That margin is as uncertain as the predictions above. The plan holds only if the live gates land. If F-RESP or F-PERSIST fails, the scores need redoing before more is built (see [THESIS](THESIS.md)).

What would change a row today:

- Real-time interaction rises when `/runs/canonical` exists and `/proof` shows measured response numbers. It falls if F-RESP fails.
- Creativity rises with F-BREADTH evidence. The "no entry on Orbis" statement comes from the builder's own scan and is not exhaustive.
- Functionality needs a live deploy and a working `/try`. Neither exists yet.

The field benchmarks come from public project pages the builder read while researching. They describe other entries and carry no ranking.
